## 1. Executive Architectural Stance: The "Operate" Mode

Most AI-generated prototypes fail in production because they design for **"Persuade"** (flashy marketing pages with gigantic hero text, empty whitespace, and decorative loops) instead of **"Operate"** (high-throughput enterprise tools where analysts, legal officers, and researchers work for 8 hours a day).

### 1.1 The Operational Mandate
* **Earned Familiarity**: The interface must disappear into the user's task. Standard enterprise affordances (tables, filters, tabs, drawers, search inputs) outrank avant-garde novelty.
* **Information Density as a Virtue**: Knowledge workers require high data density. They want to see 15–20 document rows per screen, status badges, chunk counts, and coordinate markers without scrolling through miles of padding.
* **Mathematical Grid Discipline**: Every container, gap, and padding step snaps to an explicit 4px/8px modular scale.
* **Modal Discipline**: Modals interrupt cognitive flow. Use **Slide-over Drawers (Sheets)** for deep inspection (document chunks, citations, job logs) and reserve dialogs strictly for destructive confirmations (delete document).

### 1.2 Enterprise Dial Calibration (`/design-taste-frontend`)
```
┌────────────────────────────────────────────────────────────────────────┐
│                   ENTERPRISE CORE DIALS CONFIGURATION                  │
├──────────────────────┬──────────────────────┬──────────────────────────┤
│ DESIGN_VARIANCE: 4   │ MOTION_INTENSITY: 2  │ VISUAL_DENSITY: 8        │
│ High structural      │ Snappy, functional   │ Compact, high-throughput │
│ symmetry & precision │ state transitions    │ analytical workspace     │
└──────────────────────┴──────────────────────┴──────────────────────────┘
```
* **`DESIGN_VARIANCE: 4`**: Highly disciplined layout. Tables are aligned, cards follow fixed structural geometry, and controls maintain predictable positions across all 5 screens.
* **`MOTION_INTENSITY: 2`**: 150ms–200ms micro-transitions. Motion exists solely to convey state (tab switch, drawer slide, hover state, BullMQ step pulse). Zero decorative page-load loops.
* **`VISUAL_DENSITY: 8`**: Data-dense cockpit feel. Compact table row height (`44px`), concise padding (`px-3 py-2`), and tabular numerical figures (`tabular-nums`).

### 2.2 Spatial Scale & Radius Geometry
* **Spacing Scale**: Base 4px modular unit:
  * `space.1: 4px` · `space.2: 8px` · `space.3: 12px` · `space.4: 16px` · `space.6: 24px` · `space.8: 32px`.
* **Corner Radius Hierarchy**:
  * `radius.sm: 4px` — Badges, format pills, inline tags.
  * `radius.md: 6px` — Form inputs, buttons, dropdown menus, table rows.
  * `radius.lg: 8px` — Surface cards, slide-over drawers, modal dialogs.
  * *(Banned: `rounded-2xl` and `rounded-3xl` bubble cards)*.

## 3. Production Enterprise Components (Astryx Patterns)

Stitch must generate components that behave like genuine production primitives, not static wireframes.

### 3.1 Enterprise Data Grid (`/library`)
* **Header Row**: Height `40px`, background `surface.muted` (`#F8F9FA`), border-bottom `1px solid #DDDDDD`, font `12px` bold uppercase tracking `0.05em` text `#6A6A6A`.
* **Data Rows**: Height `44px`, horizontal border `1px solid #EBEBEB`, hover state `bg-[#F8F9FA] transition-colors duration-150`.
* **Column 1: Checkbox & File Info**: Checkbox (Radix) + Format Icon (SVG) + Title (`truncate max-w-[280px]`) + SHA-256 snippet (`font-mono text-xs text-[#9E9E9E]`).
* **Column 2: Format Badge**:
  * PDF: `bg-[#FFF1F2] text-[#E00B41] border border-[#FFCCD3] px-2 py-0.5 rounded text-xs font-medium`
  * DOCX: `bg-[#EFF6FF] text-[#1D4ED8] border border-[#BFDBFE] px-2 py-0.5 rounded text-xs font-medium`
  * XLSX: `bg-[#F0FDF4] text-[#15803D] border border-[#BBF7D0] px-2 py-0.5 rounded text-xs font-medium`
  * PPTX: `bg-[#FFF7ED] text-[#C2410C] border border-[#FED7AA] px-2 py-0.5 rounded text-xs font-medium`
* **Column 3: Coordinate Extraction Stats**: `text-xs text-[#6A6A6A]` showing exact counts: `4 Sheets · 38 Chunks` or `14 Pages · 48 Chunks`.
* **Column 4: Ingestion Pipeline Status**:
  * `completed`: Green dot + `bg-[#ECFDF5] text-[#047857]`
  * `processing`: Spinning loader icon + `bg-[#EFF6FF] text-[#1D4ED8] animate-pulse`
  * `failed`: Red alert icon + `bg-[#FEF2F2] text-[#B91C1C]` + inline `Retry` button
* **Column 5: Row Actions**: Sticky right column with hoverable action triggers: `Inspect Chunks` (Drawer), `Chat` (Route), `Delete` (Dialog).

### 3.2 Slide-Over Inspector Drawer (The Anti-Modal Pattern)
* **Trigger**: Clicking any row in `/library`, or clicking a citation badge in `/chat` or `/search`.
* **Width**: Fixed `480px` on desktop, full-screen on mobile.
* **Z-Index & Backdrop**: `z-50`, backdrop `rgba(0,0,0,0.4)` with instant fade-in.
* **Motion**: Right-to-left slide transition (`transform 200ms ease-out`).
* **Header**: Fixed top bar with title, format badge, close button (`Esc` shortcut key shown), and tab bar:
  * `Tab 1: Extracted Chunks & Coordinates`
  * `Tab 2: Document Metadata & Storage`
* **Content Area**: Scrollable virtualized feed of chunk cards with coordinate tags (`Sheet1!A14:D18`) and unedited raw text excerpts.

### 3.3 Multi-Mode Search Workbench (`/search`)
* **Search Input Container**: Crisp white card with `border: 1px solid #DDDDDD` and keyboard shortcut badge (`⌘K`).
* **Segmented Mode Switcher**:
  * Three connected tabs: `Hybrid (RRF)` *(Active)* | `Semantic` | `Keyword`.
  * Active tab has `bg-[#222222] text-white shadow-sm rounded-md`.
  * Inactive tabs have `text-[#6A6A6A] hover:text-[#222222]`.
* **Result Card Anatomy**:
  * Top bar: File format badge + Document title + **Coordinate Badge** (`Sheet: Summary | Rows: A14:D18`) + Relevance Score (`RRF: 0.0328`).
  * Body: Verbatim text with `<mark>` keyword highlights in soft coral tint (`bg-[#FF385C]/[0.08] text-[#222222] font-semibold`).
  * Bottom bar: Quick actions: `Inspect in Drawer`, `Ask AI about this excerpt`.

### 3.4 Grounded Chat & Verifiable Citation System (`/chat`)
* **Dual-Scope Toggle**: Prominent dropdown in top bar: `All Documents (142 files)` vs. `Specific Document`.
* **Message Feed**:
  * User Message: Right-aligned or left-bordered block with user avatar.
  * Assistant Message: Left-aligned with DocuMind icon, model badge (`Gemini 1.5 Flash - Grounded RAG`).
  * **Interactive Citation Badges**: Inline badges rendered as interactive buttons:
    * `[Citation: Quarterly_Report.xlsx, Sheet: Summary, A14:D18]` ↗
    * Hover state: Underline + border color shift to `#FF385C`.
    * Click action: Slides open the Right-hand Citation Inspector Drawer.
* **Chat Input Bar**: Multi-line auto-resizing textarea with document attach button, character counter, send button, and anti-hallucination guarantee disclaimer.

## 4. Complete 8-State Resilience & Hardening Matrix

Enterprise software must handle imperfect real-world conditions. Every component on every screen must define the **Full 8-State Matrix**:

| State | Visual Treatment & Behavior |
| :--- | :--- |
| **1. Default (Idle)** | Clean flat surface, border `#DDDDDD`, primary text `#222222`. Clean and calm. |
| **2. Hover** | Subtle tint transition (`150ms`). Buttons darken 10% (`#FF385C` → `#E00B41`). Table rows shift to `bg-[#F8F9FA]`. |
| **3. Active (Pressed)**| Inset scale reduction (`scale-[0.98]`), border `#222222`. Immediate physical tactile feedback. |
| **4. Focus-Visible** | High-contrast 2px solid ring (`ring-2 ring-[#222222] ring-offset-2`). Full keyboard navigation compliance (WCAG 2.4.7). |
| **5. Disabled** | Opacity `0.45`, cursor `not-allowed`, `pointer-events: none`. Explicit tooltip explaining why action is disabled. |
| **6. Loading / Processing**| **No standalone center spinners.** Use structural skeleton blocks (`animate-pulse bg-[#EBEBEB] rounded`) matching the exact shape of incoming text and tables. |
| **7. Error / Conflict** | Border turns `#B91C1C`, surface `bg-[#FEF2F2]`. Alert icon + explicit human-readable recovery text (e.g., *"Duplicate SHA-256 hash detected: Quarterly_Report.xlsx already exists. View existing file"*). |
| **8. Empty State** | Never show a blank screen. Display a purposeful instruction card: an outlined format icon, a clear description of what is missing, and a direct CTA button (e.g., *"No documents in library yet. Drag & drop files to start coordinate-aware search"*). |

### 4.1 Data Overflow & Extreme Input Hardening
* **Long Filename Handling**: Use `truncate` with a CSS tooltip on hover for long names (e.g., `Consolidated_Financial_Statement_FY2026_Q3_Final_Approved_v2.xlsx` → `Consolidated_Financial_...v2.xlsx`).
* **Table Flex Shrink**: All flex items inside table cells must have `min-w-0` to prevent horizontal text overflow from breaking column widths.
* **Tabular Numbers**: Apply `font-variant-numeric: tabular-nums` to all numbers, latencies, chunk counts, and dates to ensure crisp vertical decimal alignment.

## 6. Pre-Flight Quality & Craft Verification

Before finalizing any generated screen, verify it against the **Impeccable Craft Floor**:
1. **The Scannability Test**: Can an analyst scan the document table or search results and locate file formats, coordinates, and statuses in under 3 seconds?
2. **The Contrast & Accessibility Test**: Does every text-to-background pairing satisfy WCAG 2.1 AA (≥ 4.5:1 for body copy, ≥ 3.0:1 for large text)?
3. **The Drawer vs. Modal Test**: Are deep chunk inspections and citation previews opened in slide-over drawers rather than disruptive center modals?
4. **The Coordinate Test**: Does every search result and AI citation display exact coordinates (`Page Number`, `Sheet & Row Range`, `Slide Number`)?
5. **The Real Data Test**: Does the UI use realistic filenames (`Q3_Financial_Review.xlsx`, `Vendor_Master_Agreement.docx`) rather than dummy generic placeholders (`Document 1`, `Lorem Ipsum`)?
